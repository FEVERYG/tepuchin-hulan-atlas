# 特普钦与呼兰垦务知识图谱

这是一个基于已有研究与史料线索制作的静态网页。直接打开 `index.html` 可离线使用；在线部署到 GitHub Pages 时，将本目录内容放在仓库根目录，并在仓库的 **Settings → Pages** 中选择从 `main` 分支的 `/ (root)` 发布。

网页包含人物、事件、史料和研究节点，以及可点击的关联关系、原文摘录、出处、工作性译解和证据状态。古籍电子转录仍需与书影或档案核对；部分文献目前仅见题录，并非已读原文。

“满文档案背景”节点使用黑龙江省档案馆公开网页中的外链图片，访问图片与外部文献时需要联网；该图为 1684 年材料，并非特普钦的奏折。所有第三方图文及资料版权归各自权利人所有，转载或论文引用请另核相应使用规则。
